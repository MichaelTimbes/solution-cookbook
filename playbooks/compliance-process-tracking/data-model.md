# Compliance Process Tracking Data Model

- Core: `ComplianceProcess`, `ControlTask`, `Attestation`, `RemediationTask`
- Metadata: `PolicyVersion`, `RiskLevel`, `ControlCategory`
- Governance: `ApprovalDecision`, `AuditEvent`, `OverrideAction`
- Workflow: `StatusTransition`, `Deadline`, `EscalationEvent`
- Integration: `EvidenceImport`, `RegulatoryExport`
