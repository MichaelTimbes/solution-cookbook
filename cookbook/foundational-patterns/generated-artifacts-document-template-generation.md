# Generated Artifacts (Document / Template Generation)

## Description of the pattern
Generated Artifacts produces repeatable outputs (documents, notices, structured reports) from authoritative domain data.

## Why it appears across enterprise systems
Many enterprise workflows end in externally consumable artifacts that must be correct, traceable, and reproducible.

## Typical implementation capabilities
- [Template / Merge Fields Document Generation](../capabilities/template-merge-fields-document-generation.md)
- [Import / Export Pipelines](../capabilities/import-export-pipelines.md)
- [Audit Log + Provenance](../capabilities/audit-log-provenance.md)

## Example archetypes that rely on it
- [CMS / Wiki / Knowledge Base](../archetypes/cms-wiki-kb.md)
- [Document Management System](../archetypes/document-management-system.md)
- [CRM](../archetypes/crm.md)

## Common failure modes when ignored
- Inconsistent generated outputs across channels
- Broken merge templates in production
- Missing evidence for what was generated and delivered
